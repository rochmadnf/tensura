# Fondasi pertanyaan surat

Backend mulai mendukung konfigurasi pilihan tunggal, angka, nominal, dan rentang tanggal. Opsi pilihan tunggal memiliki identitas tersimpan serta validasi kepemilikan. Konversi angka dan Rupiah/Sen memakai paket terbilang.

Tahap ini merupakan fondasi backend. Pilihan dan formulir baru belum tersedia pada halaman web; integrasi dokumen serta Kalender Kerja mengikuti tahap berikutnya.
