Pemeliharaan antarmuka dan pemeriksaan konsistensi UI setelah rilis font dokumen.

- **Komponen UI lebih konsisten.** Pencarian, peringatan, badge, dan kontrol unggah memakai komponen bersama dengan token desain aplikasi.
- **Aksesibilitas kontrol pencarian.** Tombol ikon untuk mencari dan menghapus kata kunci memiliki label serta tooltip yang jelas.
- **Pemeriksaan UI lebih fleksibel.** `check:ui` dapat membandingkan perubahan terhadap basis tertentu, termasuk cabang utama, dan menampilkan pesan yang lebih jelas ketika tidak ada berkas yang perlu diperiksa.
- **Rencana fitur berikutnya.** Menambahkan rancangan peningkatan impor dan ekspor templat surat.
