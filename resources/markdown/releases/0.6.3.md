# Backend Kalender Kerja

Endpoint Kalender Kerja menyediakan pola mingguan per tahun, kegiatan, libur, hari kerja pengganti, serta konfirmasi kesiapan. Data mendukung tampilan Bulan, Minggu, Hari, dan Agenda untuk integrasi frontend.

Hitungan hari kalender/hari kerja tersedia dengan rincian tanggal dan terbilang. Perubahan lintas tahun bersifat atomik; revisi usang dan pengecualian bertumpuk ditolak. Halaman serta menu kalender belum tersedia pada tahap backend ini.
