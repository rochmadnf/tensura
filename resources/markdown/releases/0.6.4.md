# Backend impor hari libur Indonesia

Pengambilan hari libur Indonesia kini tersedia melalui helper PHP dan endpoint tinjauan. Admin dapat memilih libur baru untuk diterapkan, dengan opsi menyertakan cuti bersama. Data manual dipertahankan dan benturan ditampilkan untuk ditinjau.

Tinjauan terikat sesi pengguna, tahun, dan revisi kalender. Penerapan ulang tidak menggandakan data; tinjauan usang atau kedaluwarsa ditolak. Gangguan sumber tidak mengubah kalender. Tombol dan dialog web menyusul pada fase frontend.
