# Backend durasi Surat dan kalender

Pertanyaan rentang tanggal dapat menghitung hari kalender atau hari kerja, termasuk durasi dan terbilang. Hasil disimpan pada draft; menyimpan field lain tidak menghitungnya ulang secara diam-diam.

Perubahan kalender menandai hasil sebagai usang dan menahan generate, pemeriksaan, serta penerbitan sampai refresh data ditinjau dan dikonfirmasi. Penerbitan memeriksa ulang kalender sebelum mengambil nomor. Revisi dan pemulihan mempertahankan riwayat dokumen resmi.

Lima tahap backend selesai. Menu Kalender Kerja serta editor/isian pertanyaan baru tetap menunggu implementasi frontend; belum tersedia sebagai fitur web lengkap.
