# Antarmuka Pertanyaan Surat dan Kalender Kerja

Rilis ini melengkapi antarmuka frontend untuk konfigurasi pertanyaan surat lanjutan dan manajemen kalender kerja organisasi.

- **Konfigurasi Pertanyaan Surat Lengkap**: Mendukung pertanyaan jenis Pilihan Tunggal (Radio), Angka (Bulat/Desimal), Nominal (Rupiah), dan Rentang Tanggal (Hari Kalender/Hari Kerja) dengan pembuatan slug variabel otomatis, kode opsi unik, dan tombol salin token turunan.
- **Form Isian Surat & Generate Uji**: Terintegrasi langsung dengan resolver backend untuk perhitungan otomatis terbilang angka/nominal dan durasi hari kerja secara real-time, dengan pembatalan request kedaluwarsa dan penanganan kesalahan tanpa menghilangkan isian form.
- **Tampilan Baca Draft Rapi**: Memformat nilai rentang tanggal secara informatif tanpa representasi objek mentah.
- **Kalender Kerja Interaktif**: Halaman kalender Inertia dengan empat tampilan (Bulan, Minggu, Hari, Agenda), sinkronisasi URL query, manajemen pola hari kerja mingguan, konfirmasi kesiapan tahun, serta penjadwalan kegiatan, libur, dan hari kerja pengganti.
- **Pengambilan Hari Libur Nasional**: Fitur pengambilan libur resmi Indonesia dengan tinjauan status (baru, duplikat, konflik), opsi cuti bersama, dan pencegahan duplikasi data manual.
- **Ketergantungan Kalender pada Surat**: Indikator status kalender pada draft surat dan alur penyegaran data master terkonfirmasi sebelum penerbitan dokumen resmi.
