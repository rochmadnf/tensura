Periksa kelengkapan paket font dan kebutuhan font template langsung dari terminal.

- **Pemeriksaan font menyeluruh.** Jalankan `php artisan document-fonts:missing` untuk memeriksa berkas paket, checksum, metadata font, dan font yang dipakai seluruh versi template, termasuk draft, terbit, dan arsip.
- **Laporan paket dan runtime terpisah.** Font yang belum masuk paket tetap ditampilkan meskipun tersedia pada sistem server. Kebutuhan template dicocokkan dengan font paket aktif, unggahan aplikasi, dan font sistem; fallback tidak dianggap sebagai font asli yang sudah tersedia.
- **Tabel hasil pemeriksaan.** Kekurangan paket, kebutuhan font template, dan pemeriksaan yang belum lengkap ditampilkan dalam tabel terminal. DOCX hilang, berubah, rusak, atau memiliki keterbatasan pembacaan dicatat tanpa menghentikan pemeriksaan template lainnya.
- **Tambah font melalui terminal.** Gunakan `php artisan document-fonts:add "/lokasi/font.ttf"` untuk mengisi metadata dan checksum otomatis, kemudian pilih sinkron sekarang atau nanti. Opsi `--webfont` mengikuti izin font; `--sync` dan `--no-sync` tersedia untuk script tanpa interaksi.
- **Varian Tahoma yang tepat.** Paket Tahoma sudah lengkap dengan Regular dan Bold. Peringatan Italic dan Bold Italic dihapus; Cambria Regular tetap tercatat belum tersedia dalam paket.

> Pemeriksaan tidak mengubah dokumen, bukti validasi, atau database. Exit code `0` berarti tidak ada kekurangan, `1` berarti ditemukan kekurangan, dan `2` berarti sebagian pemeriksaan belum dapat diselesaikan. Gunakan `--no-interaction` untuk menjalankannya melalui script.
