Font dokumen tersedia bersama aplikasi agar hasil PDF lebih konsisten di perangkat development dan server production.

- **Paket font bawaan.** Tersedia 49 berkas dari 13 keluarga font: Times New Roman, Arial, Calibri, Cambria, Candara, Consolas, Constantia, Corbel, Courier New, Georgia, Tahoma, Trebuchet MS, dan Verdana.
- **Prioritas font yang konsisten.** Untuk setiap keluarga dan varian, aplikasi mendahulukan paket bawaan, kemudian font unggahan, font sistem server, dan font fallback. Preview browser menampilkan PDF hasil konversi yang sama.
- **Sinkronisasi paket.** Font disiapkan saat setup dan deployment tanpa instalasi global. Sinkronisasi berulang memulihkan berkas yang hilang tanpa membuat duplikat, memeriksa integritas berkas, dan menolak konflik tanpa menimpa font lama.

> Tahoma sudah lengkap dengan varian Regular dan Bold. Cambria Regular belum tersedia dalam paket. Jika tidak ditemukan dari sumber lain, aplikasi memakai fallback. Periksa tata letak PDF terbaru sebelum menerbitkan surat.
